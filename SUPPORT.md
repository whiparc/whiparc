# Getting Help

Where to go depends on what you need.

| I want to... | Go to |
| :--- | :--- |
| Ask how to use or set up Whiparc | [GitHub Discussions](https://github.com/whiparc/whiparc/discussions) |
| Share an idea or ask whether something fits the project | [GitHub Discussions](https://github.com/whiparc/whiparc/discussions) |
| Report a reproducible bug | [New bug report](https://github.com/whiparc/whiparc/issues/new?template=bug_report.yml) |
| Request a feature | [New feature request](https://github.com/whiparc/whiparc/issues/new?template=feature_request.yml) |
| Report a security vulnerability | Privately, via [SECURITY.md](SECURITY.md). Never in a public issue. |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Ask about the hosted product, billing or an account | The contact form at [whiparc.com](https://whiparc.com) |

Before opening an issue, please check:

1. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for setup and port conflicts
   (port `8080` is the most common problem).
2. Existing [issues](https://github.com/whiparc/whiparc/issues) and
   [discussions](https://github.com/whiparc/whiparc/discussions).
3. [ROADMAP.md](ROADMAP.md) for known gaps.

This is a community project with a small team, so responses are best-effort
rather than guaranteed.
